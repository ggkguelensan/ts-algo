Native cursor/Mnemonist remain cheaper choices for several FIFO workloads. Public queue preserves the original compaction/clearing policy; deque uses one streaming constructor pass, then circular-array end operations. The functional API is not a claim of universal speed superiority.

Initial shared list helpers had repeated kind branches. Separate single/double insert/unlink bodies were tested; initial raw reports remain preserved. Node double-handle editing still exceeds the relative regression gate versus legacy, and Bun single FIFO is also slower in saved cases. This is accepted for independent operations and shared ownership validation, with the explicit recommendation to use native batch/cursor or Mnemonist where handles/composition are unnecessary. It is a measured trade-off, not an algorithmic improvement; retained memory and allocation still require final profiling.

Diff stays close to the prototype; direct native loops can be cheaper. Public overloads distinguish before/after entity types and require explicit callback context when used. indexBy keeps original values and rejects duplicate keys. Neither operation supplies a storage or reactive engine.
