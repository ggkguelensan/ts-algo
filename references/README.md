# Теоретические референсы

Учебные реализации для изучения, тестов и сравнения производительности.
Они не входят в публичные экспорты библиотеки. Бенчмарки и тесты импортируют
их напрямую из этой директории; основной код src от них не зависит.

## Учебный Quicksort

Референсная реализация `sortedReferencesQuickSort` принимает `(references, getValue, compare, options?)`. Она сохраняет порядок равных ключей по умолчанию через сравнение исходных индексов. Это делает равные ключи различимыми для Quicksort и убирает преимущество трёхстороннего разделения на повторах. Если устойчивость в учебном варианте не нужна:

```ts
import { sortedReferencesQuickSort } from "./sorted-references-quick-sort.js";

const sorted = sortedReferencesQuickSort(references, getValue, compare, { stable: false });
```

`quickSortInPlace<T>(items: T[], compare: Compare<T>): void` изменяет массив и не гарантирует устойчивость.

Учебный `sortedReferencesQuickSort` использует трёхсторонний Quicksort с опорным из середины по позиции. Рекурсия обрабатывает меньшую часть, цикл — большую. Новые массивы при разделениях не создаются.

- Типичное время при подходящем распределении входа: `O(n log n)`; худшее: `O(n²)`.
- Стек: `O(log n)` даже при неудачных разделениях.
- Массивы: кеш значений, индексы и результат — суммарно `O(n)` памяти. Возможные выделения внутри `getValue` сюда не входят.
- При `stable: false` у учебного QS одинаковые ключи обрабатываются за один проход, `O(n)`.
- Assertions `!` ограничены индексными операциями, опираются на границы алгоритма и заполненность массивов; не создают проверок в JavaScript.

Эти оценки времени и стека относятся к учебному QS. Массивы значений, индексов и результата используются в обоих вариантах. Середина по позиции не является медианой по значению. Защита Introsort, порог сортировки вставками и медиана трёх в учебном QS не реализованы.

## Сравнение

`npm run bench` сравнивает устойчивый Quicksort с нативной сортировкой, включая
вариант с тем же кешированием. [Замеры Node/V8](../docs/benchmark-results.md).
В измеренных больших входах QS не даёт преимущества над native cached;
на organ-pipe проявляется квадратичное время. Нестабильный kernel имеет другой
контракт и не служит доказательством ускорения устойчивой сортировки.

## Предыдущая хронология

legacy-timeline.ts сохраняет прежний интерфейс времени+графа с методами для
сравнений и исторических тестов. Публичный интерфейс времени — ts-algo/time;
references не входят в npm-архив.

legacy-tree.ts сохраняет прежнее дерево со снимком сущностей и методами для
исторических сравнений. Публичное дерево — ts-algo/tree, с живым Source.
